# Website Thiệp Cưới - Quốc Thái & Mỹ Hằng

Website thiệp mời cưới được thiết kế đẹp mắt với các hiệu ứng animation và tương tác.

## 📁 Cấu trúc dự án

```
MyHangvaQuocThaiwedding/
├── index.html          # Trang chính
├── style.css           # Stylesheet chính
├── style2.css          # Stylesheet bổ sung
├── js.js               # JavaScript cho animations và tương tác
├── source/             # Thư mục chứa assets
│   ├── album/         # Toàn bộ 30 ảnh cưới chất lượng cao đã tối ưu web
│   ├── doc/           # Ảnh thiệp & ảnh nền dọc (back_thiep, cam_dep,...)
│   ├── ngang/         # Hình ảnh QR code
│   ├── re.jpg         # Ảnh chân dung Chú rể Quốc Thái
│   ├── dau.jpg        # Ảnh chân dung Cô dâu Mỹ Hằng
│   ├── meta.jpg       # Ảnh xem trước khi chia sẻ mạng xã hội
│   ├── music.mp3      # Nhạc nền đám cưới
│   └── ...
└── README.md          # File tài liệu này
```

## ✨ Tính năng

- Thiệp mời với animation zoom và hiệu ứng chuyển động
- Giới thiệu Chú Rể (Quốc Thái) và Cô Dâu (Mỹ Hằng)
- Thư mời cưới trang trọng
- Xác nhận tham dự (Google Forms) & QR mừng cưới
- Album 30 bức ảnh cưới với hiệu ứng scroll xuất hiện 2 bên
- Nhạc nền tự động phát khi người dùng tương tác
- Tối ưu hiển thị responsive hoàn hảo trên điện thoại và máy tính
